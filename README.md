# Memory Quest Kids — Fun Card Matching Game

A playful, interactive 3D card-flipping memory match game designed for children and families. Flip two cards at a time to find matching pairs across 12, 16, or 20-card grids with 4 cheerful themes!

Part of the **Gamility** game collection.

---

## 🌟 Features

- **3 Grid Sizes**:
  - **12 Cards** (6 Pairs): 3×4 grid — Quick and friendly for beginners.
  - **16 Cards** (8 Pairs): 4×4 grid — Classic memory challenge.
  - **20 Cards** (10 Pairs): 4×5 grid — Master memory quest.
- **4 Kid-Friendly Themes**:
  - 🦁 **Safari Animals**: Lion, Elephant, Giraffe, Panda, Monkey, Penguin, Fox, Koala, Dolphin, Tiger.
  - 🚀 **Space Explorers**: Rocket, Alien, Saturn, Astronaut, Flying Saucer, Telescope, Star, Comet, Satellite, Moon Rover.
  - 🍭 **Sweet Treats**: Cupcake, Donut, Ice Cream, Lollipop, Cookie, Candy, Popsicle, Cake, Macaron, Chocolate.
  - 🍎 **Juicy Fruits**: Strawberry, Watermelon, Banana, Pineapple, Grapes, Apple, Orange, Kiwi, Cherries, Avocado.
- **3D Card Flip Animations**: Tactile CSS 3D card flips with golden matching glow and playful shake on mismatches.
- **Assistance & Learning**:
  - **👀 Sneak Peek Hint**: Briefly reveals all cards for 1.5 seconds.
  - **Match Combo Streaks**: Consecutive matches trigger fire combos!
  - **3-Star Rating**: Rewards moves efficiency with celebration fanfares and confetti.
- **Pure Web Audio Synthesizer**: Zero external MP3 files! Procedural card flips, bell chimes, and victory fanfares.
- **Offline & PWA Ready**: 100% client-side code with `localStorage` high score persistence.

---

## 🕹️ Controls & Rules

- **Tap any card**: Flips card face up.
- **Tap a second card**: Flips second card.
  - **Match**: Cards lock in place with a golden glow; you get another turn immediately!
  - **No Match**: Cards gently wobble and flip back face-down after 800ms.
- **Sneak Peek**: Tap "👀 Peek" for a 1.5-second visual preview of all cards.
